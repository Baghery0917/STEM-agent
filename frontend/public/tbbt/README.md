# 生活大爆炸主题素材

来源：用户提供的素材包（原 `frontend/素材.zip`），已按用途整理。所有角色图来自同一张 Funko Pop 八人图，风格统一。

| 目录 | 内容 | 用途 |
|---|---|---|
| `characters/` | 八个角色全身透明 PNG（约 240×380） | 认可卡卡面、收藏页 |
| `avatars/` | 八个角色头像 512×512 透明 PNG | 气泡头像、讲师切换、设置页 |
| `silhouettes/` | 八个角色灰色剪影 | 未解锁卡位 |
| `backgrounds/` | 合照、海报、星空、电梯 | 登录页背景、集齐彩蛋、深色模式背景 |
| `logos/` | 原子图标、Bazinga 字样、片头字体 | 加载动画参考、Bazinga 彩蛋、登录页标题 |
| `raw/` | 未裁切的原图和未选用的合照 | 备用 |

角色文件名：`leonard` `penny` `howard` `raj` `bernadette` `amy` `sheldon` `stuart`。Stuart 不在七位讲师内，备用。

背景图选用说明：

- `group-couch-blue.png`：登录页首选，沙发 + 浅蓝底，4K。
- `group-orange.jpg`：收藏页集齐七张后的彩蛋。
- `starfield.jpg`：深色模式背景。
- `elevator-red.jpg`：404 页（已接）。
- `group-formal-gold.jpg`：收藏页七张集齐横幅。
- `sheldon-stencil-paper.jpg`：徽章墙底纹，8% 透明度。
- `bazinga-yellow.png`（logos）：Sheldon 认可卡翻牌背面。
- `four-heads-cream.jpg` / `four-heads-yellow.jpg`：空状态插画备选。
- `atom-orbit-portraits.jpg`：加载动画的轨道参考，不直接使用。

重新生成角色切图：见 `docs/design/tbbt-redesign.md` 中的素材一节。
